# TypeScript Blog Assignment

## Assignment Overview

This assignment contains eight problems and two beginner-friendly blog posts about TypeScript. Each problems with a clear explanation to help beginners understand the concepts and solve them. It also includes two beginner-friendly blog posts covering important TypeScript topics with simple explanations and practical code examples.

## Blog Posts

1. [Type vs. Interface in TypeScript](type-vs-interface.md) — Explains the differences between `type aliases` and `interface`, with guidance on when to use each.
2. [Access Modifiers in TypeScript OOP](access-modifiers.md) — Explains `public`, `private`, `protected`, and `readonly` with a class example.
